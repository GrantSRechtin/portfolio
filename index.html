Current Projects

MagFit Prosthetics

Independent research, Fall 2025 to present

An independent research project with two other students to build a prosthetic socket that adjusts its own fit using magnetorheological elastomers (MREs). I'm designing the multi-channel pressure sensing system that maps pressure inside the socket, including the analog signal conditioning and the STM32 firmware for data acquisition. I'm also writing the control software that uses that pressure data to drive electropermanent magnets, and we're starting to bring machine learning into the fitting logic.

  • STM32
  • C++
  • Circuit Design
  • Sensors
  • Data Analysis
  • Machine Learning
